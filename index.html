Day 1
🎒 준비물 · 체크리스트
한국어·영어·포르투갈어 모두 가능. 📖 위키 결과를 고르면 좌표와 사진이 같이 들어가고, 📍 지도 결과는 상점·주소·역까지 찾습니다. 결과는 현재 지도 위치 주변을 우선 보여줍니다.
☁️ 구글 시트 연동
아직 동기화하지 않았습니다.
✍️ 앱 → 시트 쓰기 (Apps Script 웹앱)
설정(1회, 시트 소유자 계정): 시트 메뉴 확장 프로그램 → Apps Script → 열린 편집기의 내용을 지우고 📜 스크립트 복사한 코드 붙여넣기 → 저장 → 오른쪽 위 배포 → 새 배포 → 유형 선택 ⚙ 웹 앱 → 실행 사용자 나, 액세스 권한 모든 사용자 → 배포 → 권한 허용(경고 화면에서 "고급 → 이동") → 웹 앱 URL 복사 → 위 칸에 붙여넣고 🔗 연결 테스트.
스크립트는 테스트 탭이 아니면 쓰기를 거부하도록 고정되어 있어 다른 탭은 건드릴 수 없습니다. 쓰기는 테스트 탭 전체를 앱 일정으로 덮어씁니다.
· 읽기: 시트가 링크가 있는 모든 사용자로 공유되어 있으면 됩니다(뷰어/편집자 무관). 지정한 탭 하나만 읽습니다. 쓰기는 아래 Apps Script 웹앱을 통해서만 이루어집니다.
· 1행은 헤더입니다. 처음엔 📋 복사를 눌러 클립보드 내용을 테스트 탭 A1에 붙여넣으면 현재 일정이 그대로 들어갑니다.
· 헤더: 일차 날짜 시작 종료 시간대 유형 제목 장소 위도 경도 도착장소 도착위도 도착경도 이동수단 이모지 모델 사진 도착사진 경유지 준비물 비용 메모
· 위도·경도를 비워두면 장소/제목 이름으로 자동 검색해 채웁니다(위키 → OSM). 경유지는 이름|위도|경도|모델|사진 ; 이름|…, 준비물은 ;로 구분, 비용은 항목|금액|분류 ; …
· 불러오면 앱의 일정이 시트 내용으로 교체됩니다(준비물 체크 상태는 유지). 앱에서 수정한 뒤엔 📋 복사 → 시트에 붙여넣어 맞춰 주세요.
